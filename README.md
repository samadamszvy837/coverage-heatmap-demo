## Overview

Coverage Tool Demo is an HTML sample application created for internal team evaluation. It provides a compact way to review coverage information, change the selected contractor, and examine coverage through an internal heatmap.

The repository is intended for walkthroughs, feedback discussions, and interface checks. Rather than presenting a full production system, this demo keeps the implementation small and concentrates on the primary screens and review interactions.
